# MoveUp — Sua evolução começa em casa.

## Sobre o projeto
Projeto acadêmico da FMU, desenvolvido para o Checkpoint 1, alinhado à ODS 3 — Saúde e Bem-Estar.

## Problema
Muitas pessoas enfrentam dificuldades para manter uma rotina de exercícios físicos devido à falta de motivação, tempo, recursos financeiros ou acesso a academias.

## Público-alvo
Principalmente jovens adultos de 18 a 30 anos que desejam praticar atividades físicas em casa.

## Solução proposta
O MoveUp será um aplicativo gratuito com treinos em casa, acompanhamento de progresso, desafios e recompensas virtuais para incentivar a prática regular de exercícios.

## Funcionalidades planejadas
- Cadastro e perfil do usuário
- Treinos por nível de dificuldade
- Calendário de atividades e sequência de dias (streak)
- Desafios e conquistas
- Recompensas com MoveCoins
- Acompanhamento de progresso

## Dados públicos para fundamentação
- Vigitel — Ministério da Saúde
É uma pesquisa do Ministério da Saúde que acompanha hábitos da população adulta, incluindo a prática de atividades físicas.
Vocês podem utilizar os dados para:
Identificar a frequência de atividade física entre adultos.
Analisar indicadores de sedentarismo e atividade insuficiente.
Justificar a importância de um aplicativo que incentive exercícios.
Dado interessante: no levantamento de 2024, 33,3% dos adultos avaliados apresentaram prática insuficiente de atividade física, segundo o indicador utilizado pelo Vigitel.

- PeNSE — IBGE
É uma pesquisa realizada pelo IBGE que coleta informações sobre a saúde de estudantes de 13 a 17 anos.
Vocês podem utilizar os dados para:
Analisar a prática de atividades físicas entre adolescentes.
Identificar hábitos relacionados à saúde dos jovens.
Complementar a justificativa do público-alvo do aplicativo.

## Tecnologias propostas
- Java: linguagem de programação utilizada para implementar as funcionalidades e aplicar conceitos de Programação Orientada a Objetos (POO).
- Android Studio: ambiente de desenvolvimento utilizado para criar, executar e testar o aplicativo Android.
- XML: utilizado para construir as interfaces gráficas e organizar os componentes visuais.
- Firebase: serviço planejado para autenticação de usuários e armazenamento de dados.
- Git e GitHub: ferramentas utilizadas para versionamento, organização, documentação e compartilhamento do código-fonte.
